# Changelog

All notable changes to **Property Key Support** are documented here.

## 1.1.0

- Richer code completion with message text preview and source file name
- Support for `ValidationMessages.properties` and `messages_*.properties` locale files
- Rename refactoring between Java annotation keys and property files
- Quick fix to create missing keys in `messages.properties`
- Gutter icon for unresolved property keys
- Plugin signing configuration for JetBrains Marketplace publishing

## 1.0.0

- Initial release
- Go to declaration from braced keys in Java `message` attributes to `messages.properties`
- Find usages from property keys back to validation annotations
- Code completion for `message` attribute values (inserts braced keys)
- Unresolved key highlighting via IntelliJ reference resolution
